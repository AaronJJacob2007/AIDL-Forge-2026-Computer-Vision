# assets/demo

Place demo assets here — e.g. a short screen recording (GIF or MP4) of the completed finger-counting application in action, used to illustrate the project in the root `README.md`.

Suggested contents:

- `finger-counting-demo.gif` — short looping clip of the completed app detecting a hand and counting fingers
- `web-dashboard-demo.gif` — short clip of the FastAPI + frontend integration demo

Keep file sizes reasonable (a few MB at most) since these will live in Git history. Prefer GIF over MP4 for anything under ~10 seconds so it renders inline on GitHub without a video player.
