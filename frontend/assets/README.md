# frontend/assets

Place static assets used by the frontend dashboard here — icons, logos, or images referenced from `index.html` and `style.css`.

Suggested contents:

- `logo.svg` — workshop or event branding shown in the dashboard header
- `favicon.ico` — browser tab icon
- `hand-icon.svg` — small icon used next to the live finger count display

Keep assets small and optimized (SVG preferred for icons/logos) since the frontend is a lightweight static page with no build step or bundler.
