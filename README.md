## 🚀 Overview

Build a **real-time hand tracking application** using **OpenCV**, **Google's MediaPipe Tasks API**, and **Python** through an interactive hands-on workshop.

This repository accompanies the **Computer Vision Workshop** conducted during **AIDL Buildathon Forge 2026** at **Fr. Conceicao Rodrigues Institute of Technology (FCRIT)**.

Participants progressively build a complete Computer Vision application through four guided coding checkpoints while learning the fundamentals of image processing, hand landmark detection, and AI-powered vision systems.

# ✨ What You'll Build

Throughout the workshop you'll progressively build:

- 📷 Live webcam capture
- ✋ Real-time hand detection
- 🎯 21-point hand landmark prediction
- 🎨 Manual landmark rendering
- ✋ Finger counting
- 🌐 FastAPI backend integration
- 💻 Frontend visualization
- 🚀 Bonus Computer Vision projects

---

# 🎯 Learning Outcomes

After completing this workshop you'll be able to:

- Understand Computer Vision fundamentals
- Capture webcam streams using OpenCV
- Detect hands using the MediaPipe Tasks API
- Convert normalized landmark coordinates into pixel coordinates
- Draw landmarks manually with OpenCV
- Implement finger counting logic
- Build REST APIs using FastAPI
- Connect AI models to web applications
- Organize projects using Git and GitHub

# 🚀 Getting Started

1. Obtain the workshop repository (either by cloning it from GitHub or downloading the ZIP provided by the instructor).

2. Follow the environment setup instructions in **setup.md**.

3. Open the **starter/** folder.

4. Begin implementing each checkpoint during the workshop.

---

# ▶ Running the Project

## Starter

```bash
cd starter
python hand_tracking.py
```

---

## Checkpoint 1 Solution

```bash
cd checkpoint-1-solution
python hand_tracking.py
```

---

## Completed Solution

```bash
cd completed
python hand_tracking.py
```

---

## Backend

```bash

uvicorn main:app --reload
```
